# Демонстрація

Тут мають бути файли реальної демонстрації (`demo.mp4`/`demo.mov`) та результати перевірки `quality_before.json`, `quality_after.json` після локального запуску моделі. Змонтованого чи вигаданого відео в цій збірці немає.

Сценарій: показати `ollama list`, запуск `python3 app/server.py`, роботу вебсторінки, аналіз P0301 і випадку перегріву та один приклад правильної реакції на відсутність Ollama. Результати завантажити разом із кодом у репозиторій.
