# АвтоДіагност — лабораторна робота №4

Вебзастосунок первинного аналізу симптомів автомобіля та кодів OBD-II. Працює локально через Ollama та його OpenAI-сумісний API. Для запуску застосунку потрібен Python 3.10+ та Ollama. Хмарний API не використовується.

## 1. Установлення

Завантажити [Ollama](https://ollama.com/download) та запустити її. У терміналі:

```bash
ollama pull qwen3:1.7b-q8_0
ollama pull qwen3:1.7b-q4_K_M
```

## 2. Запуск

Із теки `lab4` запустити:

```bash
python3 app/server.py
```

Відкрити в браузері http://127.0.0.1:8000. Заповнити марку/модель авто, симптоми та за потреби код помилки. Натиснути «Проаналізувати». Результат відображається в режимі стрімінгу. Якщо Ollama не запущено, застосунок повідомить про помилку.

Можна змінити модель за замовчуванням: `AUTO_MODEL=qwen3:1.7b-q8_0 python3 app/server.py`.

## 3. Параметри генерації

- `temperature=0.2` — низька випадковість у технічних поясненнях
- `max_tokens=400` — обмеження відповіді, щоб мала модель не генерувала безконечно
- `num_ctx=4096` — достатньо для одного опису несправності та короткого висновку
- `reasoning_effort=none` — мінімізує затримку через приховані міркування Qwen3
- `seed=1` — зменшення варіативності

Системний промпт змушує відділяти ймовірні причини від підтвердженого діагнозу та містить правила безпеки.

## 4. Тести продуктивності

Установити лише для бенчмарку: `python3 -m pip install openai`.

Виконувати **з теки `lab4`**, щоб CSV утворився у правильному місці:

```bash
python3 app/bench.py --base-url http://localhost:11434/v1 --model qwen3:1.7b-q8_0 --label before --reasoning-effort none --concurrency 1 2 4 --requests 8 --prompts app/bench_prompts.txt
python3 app/bench.py --base-url http://localhost:11434/v1 --model qwen3:1.7b-q4_K_M --label after --reasoning-effort none --concurrency 1 2 4 --requests 8 --prompts app/bench_prompts.txt
```

Скрипт викладача збережено без зміни механізму вимірювання. Він запише фактичні `TTFT`, `tokens/s` та throughput у `lab4/bench_results.csv`.

Після цього перевірити якість на однакових 10 випадках:

```bash
python3 app/quality_eval.py --model qwen3:1.7b-q8_0 --label before
python3 app/quality_eval.py --model qwen3:1.7b-q4_K_M --label after
python3 app/summarize.py
```

Відповіді збережуться у `demo/quality_before.json` і `demo/quality_after.json`. Правильність оцінюється вручну за полем `expected`. Потрібно переглянути всі 10 відповідей, зазначити хоча б одну помилку та перевірити, чи її виправляє точніший системний промпт.

## 5. Демонстрація

Зробити запис екрана з перевіркою серверного статусу, одним типовим випадком (`P0301`) та критичним (`перегрів`). Зберегти відео у `../demo/`. Дані реальних тестів не слід підміняти прикладами.
