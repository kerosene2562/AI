# Лабораторна робота 4 — локальний запуск і оптимізація моделей

1. Відкрити `local_models_demo.ipynb` у Google Colab, увімкнути GPU T4 та виконати всі клітинки. Відповіді на теоретичні питання знаходяться наприкінці ноутбука. Для сліпого порівняння заповнити `VOTES` своїми оцінками після перегляду відповідей.
2. Для локальної частини встановити Ollama, виконати інструкцію з `app/README.md`, запустити застосунок і `before`/`after` бенчмарки.
3. Запустити оцінку 10 промптів, перевірити відповіді та описати фактичну помилку моделі у звіті. Записати коротке відео роботи в `demo/`.
4. Завантажити всю папку `lab4/` до публічного репозиторію і подати посилання через форму викладача.

Результати роботи. У Google Colab виконав експерименти з моделями та різними варіантами квантизації. Локально на MacBook протестував Qwen3 1.7B у варіантах Q8_0 та Q4_K_M. Результати вимірювань збережені у bench_results.csv. Після переходу на Q4_K_M швидкість генерації для одного клієнта зросла з 14,5 до 16,7 токенів/с. Також провів оцінювання 10 автомобільних запитів для кожної моделі.
